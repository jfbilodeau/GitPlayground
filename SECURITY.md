# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `GitPlayground`, please report it privately so we can address it before public disclosure.

- Email: [project-owner@example.com] (replace with an actual contact)
- PGP key: (optional) Provide a PGP key or other secure channel if available

When reporting a vulnerability, include:

- A clear description of the issue and impact
- Steps to reproduce (proof-of-concept or test case)
- Affected versions and environment details (OS, .NET SDK)
- Any suggested fixes or mitigation steps

## Response Process

We will respond to vulnerability reports within 48 hours to acknowledge receipt. We aim to provide a remediation plan or patch within 30 days depending on severity. For critical vulnerabilities, we will prioritize fixes and coordinate disclosure timing.

## Supported Versions

We support the latest release and the previous minor release. If your report affects older unmaintained versions, we may provide guidance but cannot guarantee patches for those releases.

## Disclosure Policy

Do not publicly disclose a vulnerability until a fix has been released or maintainers have agreed on a coordinated disclosure schedule.

Thank you for helping keep `GitPlayground` secure.

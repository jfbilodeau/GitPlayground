# Git Playground
## A GitHub Foundation Demo

This is a demo of what we can do with GitHub. This demo includes:

- Git
- Pull Request
- GitHub Actions
- GitHub Copilot
- *...and more!*

## To use the demo

Here are the steps to use the demo

1. Fork the repository
1. Clone on your local machine
1. Make changes
1. Push back to **GitHub** and watch the magic take place!

### Dependencies

| Dependency | Purpose | Minimum Version | Install |
|---|---|---:|---|
| Git | Source control: clone, commit, push, PRs | 2.20 | https://git-scm.com/ |
| Node.js | Build tools & runtime (if project uses JS/TS) | 16 LTS | https://nodejs.org/ |
| npm | Node package manager (comes with Node.js) | 8 | Included with Node.js |
| Yarn (optional) | Alternative package manager | 1.22 | https://yarnpkg.com/ |
| Docker (optional) | Containerize or run local services | 20.10 | https://www.docker.com/ |
| Visual Studio Code (recommended) | Editor with Git + GitHub extensions | Latest | https://code.visualstudio.com/ |
| GitHub CLI (optional) | Manage issues, PRs and workflows from terminal | 2.0 | https://cli.github.com/ |
